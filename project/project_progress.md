## Архитектура и общие правила

- Отдельные `backend/` (Rust Axum/SQLx) и `frontend/`, общий Compose. PostgreSQL — источник постоянных данных; Redis — временные коды/лимиты/сессии по необходимости; Garage — приватное S3-хранилище. Browser использует `/api` через Vite/nginx; cross-origin API не нужен. Локальный одноузловой Garage **не резервирует** данные.
- Production проверялся Docker (ранние этапы), затем Podman 5.8.3 + podman-compose 1.6.0. Podman-тома не переносятся автоматически из Docker. Контейнеры применяются с `--force-recreate`; `.env`, секреты и тома сохранять. Шесть сервисов healthy на последней приёмке.
- Время: IANA timezone, UTC для моментов; ISO-дни 1–7; конец расписания включителен; календарные интервалы, запрос до 366 дней. При DST повторе расписания выбирать первый момент, при пропуске — ближайшую допустимую минуту (в том числе следующий день). Для **фактических событий** интимного журнала DST-повтор выбирается явно, несуществующее время отклоняется. Timed Today/календарь/поиск вычислять по `starts_at` UTC в зоне профиля; `TaskOccurrence.date` — ключ отметки по зоне расписания; без времени — дата.
- Повторы/версии: каждое появление отмечается независимо, повторные операции идемпотентны. Завершённые/отклонённые результаты и сессии имеют неизменяемые snapshots; удаление шаблона останавливает будущую генерацию, сохраняет исторические результаты только для чтения. `editable` вычисляется сервером; snapshots не хранят capability.
- Плановая длительность занятия 1–1440 минут, интервал N дней 1–3650; длинные проекты дробятся. Ежегодный countdown на 29 февраля в невисокосный год — 28 февраля.
- Pomodoro: серверное время, пауза/возобновление/reload, подтверждение по истечении интервала; связанная задача автоматически не завершается. Звуковые/push-уведомления не реализованы. Напоминания привычек видны только в открытом приложении (24-часовое окно, подтверждения), не доставляются при закрытом браузере.
- Приватность: AES-GCM с привязкой к владельцу/объекту, сессия/Origin/изоляция; `.env` исключён из git (0600). Профиль и интимные данные не передаются AI или общей аналитике без независимых явных разрешений. Медицинские заключения из пользовательского описания не считаются фактом; статистика описательная.
- Документы контрактов: `backend/README.md`, `frontend/README.md`; запуск/приёмка — `README.md`. Приложение: `http://localhost:8081`, Mailpit: `http://localhost:8025`. Graphify не доказывает готовность кода; optional `tree_sitter_sql` отсутствует и ограничивает SQL-навигацию, не миграции.

### Этап 5: тренировки

Собственная библиотека: повторения, время, повторения×время, техника Markdown, до 3 приватных изображений, HTTP(S)-источники. Конструктор упорядоченных кругов, повторов и отдыха; последние периоды отдыха исключены. Для каждого включения упражнения отдельная линейная прогрессия: `start + floor((target-start) * elapsed_calendar_days / duration)`, с ограничением датами; снижение тоже допустимо. Это пользовательская цель, **не автоматическая рекомендация**. Одна активная тренировка на аккаунт; серверные таймеры/пауза/reload, revision/блокировки/идемпотентность, snapshots нагрузок и техники, фактические повторы, Markdown результата. Привычка может ссылаться на тренировку, но не одновременно иметь подпривычки; только полное выполнение без пропусков атомарно выполняет появление Habit. Partial/отмена сохраняют сессию без выполнения привычки; отдых можно пропустить. При смене/удалении связей соблюдаются ограничения (409, если объект используется). Пределы: 1–20 кругов, 1–20 повторов, 1–50 включений на круг, ≤500 шагов, ≤суток расчётного времени, snapshot ≤4 MiB; история по 50. ### Этап 8: AI (окончательно принят 29.10.2026)

`/ai` и `/settings`: отдельные ChatGPT Login (официальный OAuth/OIDC), OpenAI Responses API с пользовательским ключом и OpenRouter API с отдельным ключом; без автоматической смены провайдера. OpenRouter: отдельный HTTPS endpoint, ZDR/запрет сбора данных. API-ключи, OAuth-токены, чаты и preview — AES-GCM по владельцу/объекту; ключи не возвращаются браузеру.

Независимые чаты/удаление, Markdown, 4 шаблона, смена провайдера; 7 **default-off** разрешений: числовая аналитика, задачи/расписания, привычки с названиями, результаты тренировок, Markdown заметок, полная анкета профиля, минимальная интимная сводка. Один pending-запрос на аккаунт, UUID-идемпотентность, поллинг, без автоматического retry, 2-мин timeout, 5/мин и 50/час, до 200 запросов/чат и 100 чатов. ### Исправление входа после этапа 9 — 30.10.2026

Пользователь открывал `http://127.0.0.1:8081`, тогда как `.env` и работающий backend содержали `APP_PUBLIC_URL=http://localhost:8081`. ### Причина ошибки ChatGPT и настоящее подтверждение

Одно нейтральное диагностическое обращение с действующим выбранным ChatGPT Login воспроизвело транспортный формат: HTTP 200, SSE с 835 текстовыми delta, done/item и completed; в финальном completed `output=[]`, хотя текст уже пришёл раньше. Старый парсер искал ответ только в финальном output и выдавал `ai_invalid_response`.

Парсер теперь собирает delta/done/item, поддерживает полный финальный output и считает ответ завершённым **только** после явного completed со статусом completed. Пустой финальный output не теряет ранее полученный текст; незавершённый поток не принимается и автоматически не повторяется. Пределы: SSE 16 MiB, текст 256 KiB, JSON inference 1 MiB. API-key max_output_tokens увеличен до 8192; Login по-прежнему не передаёт этот неподдерживаемый параметр. Добавлен регрессионный Rust-тест metadata-only completion.

Отдельная настоящая проверка прошла через обычные endpoints приложения с текущим подключением и синтетическим заданием «три упражнения и тренировка». Предпросмотр проверен: заметки/тренировки пусты, личные источники не передавались. Результат: **completed, 4721 байт текста, один блок предложений, четыре действия, server validation prepared_without_apply**. Сервер проверил ответ реальной модели; apply не вызывался, реальные упражнения/тренировки не создавались. Временные предложение, чат и локальная проверочная сессия удалены; настройки, credentials и личные записи не изменялись. Это отдельное доказательство внешнего inference, а не синтетическая браузерная fixture.
