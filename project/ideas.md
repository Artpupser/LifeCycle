# Для AI
Данный раздел считается информацией не предназначенной для разработки текущего приложения. Тут находятся только идеи а не архетиктурный план (КРИТИЧЕСКИ ВАЖНО НЕ ИСПОЛЬЗОВАТЬ ДАННЫЙ ФАЙЛ) 

# Список идей
- Здоровье
  - Система ведения метриков сердечно сосудистой системы, измерение давления (нижнего/верхнего) и пульса
  - Система ведения метриков активности сна, измерение данных о дыхании, звуков и разных телодвижений во время сна
  - Система отслеживания питания, подсчет калорий, витаминов и химических элементов пищи. Разные режимы питания, набор веса, сброс веса


- Сбор данных с устройств
  - Сбор и хранение метриков с мобильного устройства. Экранное время, активность приложений, цифровые привычки, поднятие телефона, уведомления, использование сайтов
