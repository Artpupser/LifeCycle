# Bundled icon data

Icons are rendered by `@iconify/react` (MIT). The public catalog is defined by `manifest.json`; SVG data are generated with `node scripts/generate-icons.mjs` from the pinned packages in `pnpm-lock.yaml`.

- Tabler Icons: MIT, https://github.com/tabler/tabler-icons
- Circle Flags: MIT, https://github.com/HatScripts/circle-flags
- Simple Icons: CC0-1.0, https://github.com/simple-icons/simple-icons — brand marks remain subject to their owners' trademark rights.
- LifeCycle: the existing application mark in `src/assets/logo.svg`, also registered as `lifecycle:mark`.
