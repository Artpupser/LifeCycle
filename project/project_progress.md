## Архитектура и общие правила

- Отдельные `backend/` (Rust Axum/SQLx) и `frontend/`, общий Compose. PostgreSQL — источник постоянных данных; Redis — временные коды/лимиты/сессии по необходимости; Garage — приватное S3-хранилище. Browser использует `/api` через Vite/nginx; cross-origin API не нужен. Локальный одноузловой Garage **не резервирует** данные.
- Production проверялся Docker (ранние этапы), затем Podman 5.8.3 + podman-compose 1.6.0. Podman-тома не переносятся автоматически из Docker. Контейнеры применяются с `--force-recreate`; `.env`, секреты и тома сохранять. Шесть сервисов healthy на последней приёмке.
- Время: IANA timezone, UTC для моментов; ISO-дни 1–7; конец расписания включителен; календарные интервалы, запрос до 366 дней. При DST повторе расписания выбирать первый момент, при пропуске — ближайшую допустимую минуту (в том числе следующий день). Для **фактических событий** интимного журнала DST-повтор выбирается явно, несуществующее время отклоняется. Timed Today/календарь/поиск вычислять по `starts_at` UTC в зоне профиля; `TaskOccurrence.date` — ключ отметки по зоне расписания; без времени — дата.
- Повторы/версии: каждое появление отмечается независимо, повторные операции идемпотентны. Завершённые/отклонённые результаты и сессии имеют неизменяемые snapshots; удаление шаблона останавливает будущую генерацию, сохраняет исторические результаты только для чтения. `editable` вычисляется сервером; snapshots не хранят capability.
- Плановая длительность занятия 1–1440 минут, интервал N дней 1–3650; длинные проекты дробятся. Ежегодный countdown на 29 февраля в невисокосный год — 28 февраля.
- Pomodoro: серверное время, пауза/возобновление/reload, подтверждение по истечении интервала; связанная задача автоматически не завершается. Звуковые/push-уведомления не реализованы. Напоминания привычек видны только в открытом приложении (24-часовое окно, подтверждения), не доставляются при закрытом браузере.
- Приватность: AES-GCM с привязкой к владельцу/объекту, сессия/Origin/изоляция; `.env` исключён из git (0600). Профиль и интимные данные не передаются AI или общей аналитике без независимых явных разрешений. Медицинские заключения из пользовательского описания не считаются фактом; статистика описательная.
- Документы контрактов: `backend/README.md`, `frontend/README.md`; запуск/приёмка — `README.md`. Приложение: `http://localhost:8081`, Mailpit: `http://localhost:8025`. Graphify не доказывает готовность кода; optional `tree_sitter_sql` отсутствует и ограничивает SQL-навигацию, не миграции.

Countdown: категории, ежегодность, оставшееся время. Pomodoro: серверная сессия, пауза/reload/отмена/завершение. Исправлены рассинхронизация статусов, дедлайны, фильтры дат и DST. По окончании: backend 26 тестов, frontend 12, 4 Chromium E2E, `smoke.py`, `auth_smoke.py`, `core_smoke.py`, миграции 1–3; блокеров нет.

Версии правил с сегодняшнего дня, snapshot прежних результатов, корректировка истории до удаления/архива (правило исходного этапа). Today/календарь и серверные напоминания с подтверждением, только при открытом UI. Защита от изменений через обычный Task API. ### Этап 5: тренировки

Собственная библиотека: повторения, время, повторения×время, техника Markdown, до 3 приватных изображений, HTTP(S)-источники. Конструктор упорядоченных кругов, повторов и отдыха; последние периоды отдыха исключены. Для каждого включения упражнения отдельная линейная прогрессия: `start + floor((target-start) * elapsed_calendar_days / duration)`, с ограничением датами; снижение тоже допустимо. Это пользовательская цель, **не автоматическая рекомендация**. Одна активная тренировка на аккаунт; серверные таймеры/пауза/reload, revision/блокировки/идемпотентность, snapshots нагрузок и техники, фактические повторы, Markdown результата. Привычка может ссылаться на тренировку, но не одновременно иметь подпривычки; только полное выполнение без пропусков атомарно выполняет появление Habit. Partial/отмена сохраняют сессию без выполнения привычки; отдых можно пропустить. При смене/удалении связей соблюдаются ограничения (409, если объект используется). Пределы: 1–20 кругов, 1–20 повторов, 1–50 включений на круг, ≤500 шагов, ≤суток расчётного времени, snapshot ≤4 MiB; история по 50. Миграция 0005, backend 37, frontend 12, 8 Chromium, `workouts_smoke.py` и регрессии прошли; блокеров нет.

### Этап 6: интимный журнал

`/sex`: фактические события секса/мастурбации, несколько даже в одинаковое время, обязательны тип/местное время/IANA-зона; остальные поля добровольны и различают неизвестно/0/false. Анкета: длительность, эякуляции, игрушки, смазка, обстановка/одежда/эмоции/повтор, Markdown; для секса — защита/партнёр/позы/виды, для мастурбации — порноисточники/ощущения. Поля и тексты AES-GCM; в БД открыты UUID/владелец/время/revision/служебные метаданные (не E2EE). Не попадает в общие `activity_events`, Tasks/Today/календарь/поиск. Фильтры/пагинация по 50, 1–366 дат, статистика **только внесённых записей**, пропущенные измерения не усредняются, отсутствие записи не означает воздержание. Revision даёт 409 при конфликте; DELETE удаляет анкету, но не общие приватные media и не физические резервные копии БД. Лимиты: длительность 1–1440 мин, эякуляции 0–100, списки до 30×500 символов. Миграция 0006; backend 41, frontend 12, 10 Chromium, `intimacy_smoke.py`/регрессии прошли; блокеров нет.

### Этап 7: аналитика и физическое удаление

Удаление заметок/папок/задач/привычек/countdown/упражнений/планов теперь физическое из основной таблицы (GET/PUT/DELETE → 404), не `archived_at`; дочерние записи сохраняются с освобождением связи, Pomodoro отвязывается. Связанные упражнения/планы требуют предварительно снять связи (409). Исторические snapshots/версии/сессии остаются только для чтения; будущие появления прекращаются. ### Этап 8: AI (окончательно принят 29.10.2026)

`/ai` и `/settings`: отдельные ChatGPT Login (официальный OAuth/OIDC), OpenAI Responses API с пользовательским ключом и OpenRouter API с отдельным ключом; без автоматической смены провайдера. Для ChatGPT: loopback `127.0.0.1` HTTP callback, динамическая регистрация, PKCE/state/nonce, JWT/JWKS/issuer/audience/exp/iat, revision, refresh/revoke, выбор моделей; Login не гарантирует бесплатность/лимиты и не заменяет API-ключ для удалённого сервера без отдельного web-client approval. OpenRouter: отдельный HTTPS endpoint, ZDR/запрет сбора данных. API-ключи, OAuth-токены, чаты и preview — AES-GCM по владельцу/объекту; ключи не возвращаются браузеру.

Независимые чаты/удаление, Markdown, 4 шаблона, смена провайдера; 7 **default-off** разрешений: числовая аналитика, задачи/расписания, привычки с названиями, результаты тренировок, Markdown заметок, полная анкета профиля, минимальная интимная сводка. Фото не передаются, выдуманных метрик сна нет; AI не может менять данные. Перед отправкой — точный зашифрованный preview тела/модели/разрешённого контекста/вопроса/до 10 успешных предыдущих пар текущей revision; TTL 5 минут, без обращения к провайдеру. Смена прав/подключения отменяет pending, удаляет preview, исключает старые чаты из нового контекста, но не может отозвать ранее отправленное наружу. Один pending-запрос на аккаунт, UUID-идемпотентность, поллинг, без автоматического retry, 2-мин timeout, 5/мин и 50/час, до 200 запросов/чат и 100 чатов. OpenAI inference через публичный Responses API с `store:false`, SSE `stream:true`; неподдерживаемые параметры не передаются.

Реальная внешняя приёмка: ChatGPT OAuth успешен; обнаружены и устранены ошибка загрузки каталога `/v1/models` размером 655826 B (для каталога предел увеличен с 256 KiB до 2 MiB) и блокировка редактора при несохранённой модели. Выбор/сохранение модели явный; ввод/черновики доступны при незаписанных настройках, но отправка требует сохранения. Черновики разделены по chat ID и живут только в памяти страницы, не в storage. **Пользователь подтвердил ответы, сервер независимо подтвердил `provider=openai`, `auth_mode=login`, `enabled=true`, модель `gpt-5.6-luna`, настоящий `ai_turns.status=completed` и непустой SSE-ответ**. Ранее отклонённый turn остаётся failed и не повторялся. Альтернативные платные inference через API-ключи не тестировались из-за отсутствия ключей; их контракты и ошибки проверены. Миграции 1–9 успешны, backend 48 unit + 7 foundation, frontend 13, 12 Chromium E2E, все релевантные smoke/regression, сборки/линтеры прошли. Шесть сервисов healthy, секреты и тома не заменялись; последний AST Graphify: 1612 узлов/5193 связи. Известных блокирующих ошибок этапа 8 нет.
