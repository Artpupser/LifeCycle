# Bundled marks and colors

Service icons come from the existing Iconify Simple Icons pack. Natural brand colors are bundled in `brand-colors.json`, sourced from the [Simple Icons catalog](https://github.com/simple-icons/simple-icons/blob/develop/data/simple-icons.json), with compatibility entries for brands removed from newer releases. Monochrome marks use their light/dark variants for readability.

Operator marks live in the same public catalog and visual picker. MegaFon and Yota paths are adapted from [Arcticons via Iconify](https://icon-sets.iconify.design/arcticons/) (Arcticons contributors, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)); changes apply natural brand strokes and a thicker small-size line. The MTS, t2 and Beeline marks are bundled simplified vector treatments in their primary brand colors. No operator asset or icon name causes a runtime request to a third party.

- Emoji: Twemoji / Twitter, unchanged SVG subset distributed through `@iconify-json/twemoji`, CC BY 4.0: https://github.com/twitter/twemoji and https://creativecommons.org/licenses/by/4.0/. Attribution also appears in the shared picker. No remote icon API is used.
- Zodiac: bundled Tabler `zodiac-*`; conventional civil-date boundaries from https://www.britannica.com/topic/zodiac (western tropical signs).
